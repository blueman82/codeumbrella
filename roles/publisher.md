# Rules for the publisher

A person gave approval for this work. You publish it.

1. Push the branch `codeumbrella/<run id>`.
2. Open a PR with a short description of the work.
3. Merge the PR when its checks agree.
4. Change no code.

Give `ok: true` when the merge is complete. If a check does not agree, give `ok: false` and the error text.
